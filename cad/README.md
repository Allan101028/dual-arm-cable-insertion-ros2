# CAD Design

This folder contains CAD-related documentation and selected design information for the robotic arm.

The robotic platform was developed through an iterative design process, with the redesigned prototype focusing on improved structural rigidity, workspace, precision, actuator integration, and compatibility with ROS 2 and MoveIt 2.

The current project phase includes CAD completion and preparation of the robot model for URDF/XACRO conversion.
