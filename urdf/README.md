# URDF / XACRO

This folder will contain the URDF/XACRO robot description developed for ROS 2 and MoveIt 2 integration.

## Current Status

The robot description is currently under development as part of the CAD-to-ROS 2 workflow.

Future files will include the robot's URDF/XACRO description, joint definitions, links, materials, and related configuration required for simulation and motion planning.
